# Curaçao FIR (TNCF) – EuroScope package

Download page for the Curaçao FIR (TNCF) EuroScope sector package. EuroScope can install and update it by itself.

## Installing

1. In EuroScope, open **Open SCT → Download Sector Files…**.
2. Fill in the fields below the provider list, then click **New**:
   - **Name:** `TNCF Curacao FIR - VATCAR`
   - **URL:** `https://github.com/East-Caribbean-Zone/TNCF-Release-Package/releases/latest/download/TNCF_Sector_Provider.txt`
   - **Filename:** `TNCF_Sector_Provider.txt` in the folder where you want the package, e.g. `C:\EuroScope\TNCF\TNCF_Sector_Provider.txt`. The package is unpacked into that folder.
3. Tick **A** on the new provider and click **Download**.
4. Under **Provided Sector Files**, tick **A** on the package you need and click **Download**:
   - **TNCF Curacao FIR** for Aruba, Curaçao and Bonaire (`Curacao.prf`)
   - **TNCF Juliana TMA** for St Maarten (`Juliana.prf`)

   They're separate downloads, so you can install one or both.

EuroScope then checks for updates at start-up and offers to switch your profiles to each new version. Each update overwrites the package files in that folder, so keep personal changes in your own copies.

You can also download the package by hand from [Releases](https://github.com/East-Caribbean-Zone/TNCF-Release-Package/releases/latest).
